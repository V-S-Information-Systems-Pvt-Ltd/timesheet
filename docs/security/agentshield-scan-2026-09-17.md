## Reviewed disposition

- **587 false positives:** 585 npm `sha512` integrity hashes in `package-lock.json` were misclassified as Azure storage keys, and 2 ordinary VS Code settings findings were misclassified as agent configuration issues.
- **12 agent-instruction hardening findings:** `CLAUDE.md` only delegates to `AGENTS.md`, so AgentShield reports missing explicit prompt-defense language. These are hardening recommendations; the scan did not identify an injected payload.
- **4 local agent-configuration hardening findings:** `.commandcode/settings.json` contains local test database credentials, broad shell permissions with an empty deny list, and no PreToolUse security hook. The directory is Git-ignored.

The scanner did not identify an application-code vulnerability in this run; its target was agent/editor configuration. The raw D/54 score should therefore not be interpreted as the application security grade.
