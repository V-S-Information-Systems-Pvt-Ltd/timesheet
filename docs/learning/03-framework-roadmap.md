## Framework requirements versus project choices

- Next.js conventions: route/layout/page filenames, client boundary behavior, framework-managed rendering, and Request/Response handlers. Consult installed Next docs before changing them.
- React conventions: components, Hooks, render/state semantics, and hook rules. This project chooses the components and their composition.
- Project choices: domain ports/adapters, dual backends, explicit result shapes, browser data facades, a shared schema package, and the particular role model.
- Library behavior: Zod parses runtime input, `pg` executes SQL, Supabase mediates provider access, and `jose` handles JWT operations. Application policies remain separate from these libraries.
- Not applicable to the inspected stack: Redux-specific state lessons, Express middleware conventions, Prisma models, and Pages Router lifecycle APIs. No lesson should invent those abstractions merely because they are common elsewhere.
