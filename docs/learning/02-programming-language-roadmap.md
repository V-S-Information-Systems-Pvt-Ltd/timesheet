# Language roadmap — Levels 1 and 2

> **Update (2026-10-16):** The Supabase backend and the `NEXT_PUBLIC_BACKEND` switch were removed; native PostgreSQL with in-app auth is the only backend. References below to Supabase mode, Supabase adapters/RLS or the dual-backend design describe the previous architecture.

Work in ID order. Each row is a learning topic with objectives, prerequisites, relevance, source, exercise, and observable understanding criteria. Exercises begin as read-only predictions. One topic may take several short lessons; no schedule or proficiency is assumed.

Sources are anchors for future lessons, not a request to read each full file now. Ask the tutor to retrieve one small relevant function at a time. Terms are defined in [the glossary](09-technical-glossary.md).

## How proficiency is assessed

Use prediction → explanation → a new case. Correctly repeating an example is insufficient if you cannot explain the changed input. The tutor records specific evidence in [progress](08-learning-progress.md), keeps unknowns explicit, and revisits prerequisites when answers expose gaps.

A compile-time error is a tool teaching signal. A runtime error is observed execution behavior. Passing one does not prove the other, and neither proves business authorization.

## Topics to defer or mark not applicable

- TypeScript decorators and heavy class inheritance are not prerequisites for the examined application slices. Study only when a real example needs them.
- JSX is relevant at Level 3, after ordinary functions and objects.
- ORM entity/change-tracking lessons are not applicable to the current SQL/Supabase persistence paths; teach queries and ports instead.
- Kotlin/Swift/C++ bridge development is optional advanced mobile work. Those languages' compiler versions and detailed bridge behavior were not audited here.
- Rust is not the implemented application stack examined here. Existing Rust-planning documents do not make this a Rust application.

Continue with [Levels 3–6](03-framework-roadmap.md) after the relevant language prerequisites are demonstrated.
